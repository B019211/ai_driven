# AI駆動CI/CD 学習メモ（次回引き継ぎ）

## 今日の到達点

AI生成YAMLの破損問題について、
binary corruption ではなく
text corruption レベルまで問題を縮小できた。

以下を導入済み：

* UTF-8 normalize
* ASCII printable only
* dangerous chars remove
* newline normalize
* YAML validation before save
* INVALID YAML dump
* self-healing YAML fix loop（途中）
* path validation
* review loop

現在、
AI生成物を「信用しない」方向へ
アーキテクチャを進めている。

かなり重要な転換点。

---

## 現在の主問題

Gemini生成YAMLで以下が発生：

* key merge
* indentation collapse
* typo
* line merge

例：

db_name: testdb    mysql_root_password:

owner/group 崩れ：

0group: vboxuser

Ansible module merge：

* name: xxx      containers.podman.container:

つまり、
生成品質より
「生成後repair」が本筋。

---

## 導入済み修正

Generate Files 内で：

* ASCII_ONLY sanitize
* control chars remove
* YAML pre-parse validation

追加済み。

さらに：

```python
decoded = re.sub(
    r"([^\n])\s+([A-Za-z0-9_]+:)",
    r"\1\n\2",
    decoded
)
```

を newline normalize 後へ追加。
