# AI Driven CI/CD

## 概要

本プロジェクトは、AIを活用した自律型CI/CDパイプラインの構築を目的とする。

AIが生成した成果物をPythonパイプラインが検証・デプロイし、
実行結果を基に原因分析と修復を行い、
再検証する一連のサイクルを自動化する。

最終的には、

Generate
→ Validate
→ Deploy
→ Browser Test
→ Root Cause Analysis
→ Repair
→ Retry

を自律的に実行できるCI/CDパイプラインを目指す。

---

## 開発方針

本プロジェクトでは、AIによるコード生成そのものではなく、

- AIによる問題分析
- 自動検証
- 自動デプロイ
- Root Cause Analysis
- 自動修復
- 自動再試行

を組み合わせた「AI駆動開発」の実践と学習を目的とする。
