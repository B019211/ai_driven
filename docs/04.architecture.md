# ARCHITECTURE

## Pipeline

Generate
↓
Review
↓
Validation
↓
Deploy
↓
Browser Validation
↓
PHP Lint
↓
Root Cause Analysis
↓
Repair
↓
Retry

---

## Components

### AI Generation

成果物を生成する。

---

### Review

生成された成果物をレビューする。

---

### Python Pipeline

パイプライン全体を制御する。

主な責務：

- オーケストレーション
- Validation
- Deploy
- Retry
- 結果収集
- Repair制御

---

### Remote Validation

リモート環境上で生成物の妥当性を確認する。

---

### Browser Validation

デプロイされたWebアプリケーションへアクセスし、
実際のHTTP応答を検証する。

---

### PHP Lint

生成されたPHPコードの構文を検証する。

---

### Root Cause Analysis

Validation結果、ログ、実行結果などを分析し、
失敗の根本原因を特定する。

---

### Repair Engine

Root Cause Analysisの結果に基づき、
必要なファイルだけを修復する。

---

## Repair Flow

Validation Failure
↓
Evidence Collection
↓
Root Cause Analysis
↓
Repair Target Selection
↓
Regenerate / Repair
↓
Validation
↓
Retry
