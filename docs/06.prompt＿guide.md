# PROMPT GUIDE

## 目的

本ドキュメントは、VSCode上のGenieAIなど、
実装を担当するAIへ指示するプロンプトの設計ルールを定義する。

---

## 基本構造

プロンプトは可能な限り以下の構造で作成する。

Role

Task

Rules

Input

Attachments

Output

---

## Role

AIに期待する役割を明示する。

例：

Python Developer

PHP Developer

CI/CD Engineer

---

## Task

実施する作業を具体的に記述する。

曖昧な表現を避ける。

---

## Rules

守るべき制約を明示する。

例：

- 最小変更
- 既存構造を維持
- 不要なリファクタリング禁止
- 推測禁止
- 未提示のファイルを変更しない

---

## Input

現在のコード、ログ、エラーなど、
AIが判断材料として使用する情報を明示する。

---

## Attachments

参照すべきファイルを明示する。

ファイル名だけでなく、
必要に応じて確認対象を指定する。

---

## Output

AIが何を返すべきかを明示する。

例：

- 修正済みコード
- JSON
- ファイル一覧
- 修正内容
- テスト結果

---

## コード修正

コード修正を依頼する場合は、

- 対象ファイル
- 修正目的
- 制約
- 期待する結果

を明示する。

---

## 既存コード優先

GenieAIに未提示のコードを推測させない。

既存コードを確認してから修正させる。

---

## 最小変更

問題解決に必要な範囲だけを変更する。

---

## Bad Prompt

長い説明だけで、
何を変更するのか明確でないプロンプト。

---

## Good Prompt

Role

Task

Rules

Input

Attachments

Output

が明確で、
実装対象と期待結果が分かるプロンプト。
